One rung at a time; then ~solution/lab.py~ or ~solution/functional.py~.

* Step 1 — Oracles

** Rung 1 — graphic
Inside ~independent(S)~: a fresh ~parent = list(range(n_vertices))~, and for each
edge index in S ~find~ both endpoints. If the roots are equal the edge closes a
cycle, so return False. Otherwise union the roots.

** Rung 2 — the others
Uniform: ~len(set(S)) <= k~. Partition: count per block (~collections.Counter~) and
compare with ~capacity~. Linear: ~rank([vectors[e] for e in S]) == len(set(S))~,
with the empty set independent.

** Functional route
Each oracle is a closure returning a predicate. The graphic one is a fold over the chosen edges whose
accumulator is a tuple of component labels, or ~None~ once a cycle appears (so ~None~ absorbs the rest of the
fold). Uniform and partition are one line each; ~Counter~ counts per block.

* Step 2 — Greedy

** Rung 1
~sorted(range(n), key=lambda e: (-weight[e], e))~; loop, ~break~ at ~weight <= 0~,
and ~if independent(chosen + [e]): chosen.append(e)~.

** Functional route
A fold over the positive-weight prefix of the sorted ground set: ~takewhile(weight > 0, order)~, and a
step that keeps ~chosen + [e]~ when that is independent. Build a new list rather than appending, so every
oracle call sees exactly the set it is asked about.

* Step 3 — The axiom checker

** Rung 1
List every independent set as a ~frozenset~ (enumerate all subsets and ask the
oracle), and put them in a ~set~ for membership tests. Hereditary: for each
independent S and element e of S, check that S − {e} is in the family. Exchange:
for each pair A, B with |A| < |B|, check some b ∈ B − A makes A ∪ {b} independent.

** Rung 2 — why checking one element at a time is enough
If every S minus one element stays independent, then by induction every subset of
S is independent. So hereditary needs only single removals.

** Functional route
Build the independent family once as a set of frozensets. Then the violations are two lazy generators,
hereditary first and exchange second, and the answer is ~next(chain(hereditary, exchange), None)~: the first
witness, or none, without enumerating the rest.

* Step 4 — Matroid intersection

** Rung 1 — the graph
For the current I, and every x ∈ I, y ∉ I: let J = I − x + y. If J is independent
in M1, add arc x → y. If J is independent in M2, add arc y → x. Sources are the y
with I + y independent in M1; sinks are the y with I + y independent in M2.

** Rung 2 — search and flip
BFS from all sources at once, with ~parent~ pointers, and stop when you pop a sink.
Walk back to recover the path, then ~I ^= set(path)~. The path alternates
out, in, out, …, out, so |I| grows by exactly 1.

** Rung 3 — why shortest
The proof that I Δ path stays independent in both matroids uses the fact that a
shortest path has no "shortcut" arcs: no arc joins two vertices on the path that
are more than one step apart. BFS gives you that for free.

** Functional route
The exchange graph is a list of arcs grouped with ~tz.groupby(0, arcs)~. BFS is an unfold over ~(parent
map, frontier)~, one layer per step, cut off by ~takewhile~ when the frontier is empty; the first layer that
touches a sink ends the search. The path is ~tz.iterate~ over parents until ~None~. Intersection is an unfold
over frozensets, ~I ^ frozenset(path)~ per augmentation, until no path exists.

* Step 5 — Greedy coverage

** Rung 1
Keep ~covered~ as a set. Each round, over the unchosen indices take the max of
~(len(set(sets[i]) - covered), -i)~, so the lowest index wins ties. Append the
index and update ~covered~.

** Functional route
A fold over range(k) with state ~(chosen list, covered set)~. Each step picks the set covering the most new
elements, with ties to the lower index, and returns a new pair.
