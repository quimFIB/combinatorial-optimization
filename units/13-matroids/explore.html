One greedy, two oracles

Try: step through Kruskal on the forests, then switch to the matchings on the path and watch the heavy middle edge block both ends. Static version: greedy and exchange, on one graph.

What it shows. The same greedy loop, heaviest edge first, with the oracle deciding what "still independent" means. With the forest oracle (the graphic matroid) on the slide's graph, greedy keeps 34, 23, 01, 12 and every rejected edge closes a cycle; brute force over all 128 edge sets confirms that 18 is optimal. With the matching oracle on the path with weights 2, 3, 2, greedy takes the 3 and is stuck at 3, while the two end edges give 4.

The failure is the exchange axiom failing: $\{12\}$ is smaller than $\{01, 23\}$ but neither of the larger set's edges can join it. That witness comes from the reference matroid_witness. The greedy runs are logged copies of the reference greedy with the reference graphic and partition oracles.

An augmenting path in the exchange graph

Try: follow the sources, sinks and arcs, then the flip that grows I from one edge to two. Static version: one augmenting path, on three edges.

What it shows. The slide's three-edge path, starting from the stuck set $I = \{e_1\}$. Sources are edges that can join $I$ in $M_1$ (one edge per left vertex), sinks those that can join in $M_2$ (one per right vertex). Arcs record single swaps: $x \to y$ if swapping $x$ out for $y$ stays in $M_1$, $y \to x$ if it stays in $M_2$. The shortest source-to-sink path $e_0 \to e_1 \to e_2$ is flipped, giving $\{e_0, e_2\}$, and then no source is left.

A logged copy of the reference intersection (started from $\{e_1\}$ instead of the empty set), with its final size checked against the reference.
