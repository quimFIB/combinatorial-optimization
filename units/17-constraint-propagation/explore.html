AC-3, revise by revise

Try: step through the chain, then pick the triangle (nothing moves) and the cycle (a wipeout). Static version: AC-3, revise by revise.

What it shows. AC-3's queue of arcs and the domains it shrinks. The arrow points from the variable that supplies supports to the one being revised; the value cells under each variable cross out what goes, red for this step. The queue chips mark newly pushed arcs.

  • x < y < z: the seven revise calls of the deck's table, ending in a single value each.
  • x ≠ y ≠ z ≠ x on {0,1}: six calls, nothing removed, yet there is no solution: arc consistency is local.
  • x < y < z < x: the cycle cannot be satisfied, and AC-3 finds out by emptying z.

Data. slides/viz/traces/u17.py replays the reference ac3's queue with the reference revise and checks each run ends with the same domains and call count as ac3 itself.

A trail, written and undone

Try: step to the second propagation, then watch the two undos pop the trail newest first. Static version: A trail, written and undone.

What it shows. A store of three domains and its trail. Every change pushes (variable, old domain); a mark is the trail's length; undo pops entries back to a mark, newest first, restoring each old domain.

Data. The reference Store, NotEqual, fixpoint, mark and undo, snapshotted after each event by slides/viz/traces/u17.py.
