Branch and bound, one pop at a time

Try: step through best-first, then switch to depth-first and compare. Static versions: the tree, both orders.

What it shows. The deck's running example, $\min -x - 5y$ with $7x + 3y \le 22$ and $-3x + 3y \le 2$, solved by branch and bound. Left: the feasible polygon, its integer points, the LP optima of the nodes created so far (grey dots, the current one large), the current node's variable-bound box (dashed), and the incumbent (green square). Right: the tree as it grows, each node with its branching decision, LP bound and fate.

The runs are recorded by slides/viz/traces/u07.py, which replays the reference branch_and_bound loop with the reference most_fractional, children and colib.bb.solve_node, and checks its node count and optimum against the reference function: 5 nodes best-first, 9 depth-first.
