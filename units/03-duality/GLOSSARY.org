The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: \(\max\ 3x + 2y\) subject to \(x + y \le 4,\ 2x + y \le 6,\
x, y \ge 0\), optimal at \(x = y = 2\) with dual \((1, 1)\) and value 10.

* The dual as a bound

- primal :: The LP you started with. Here \(\max\{c^\top x : Ax \le b,\ x \ge
  0\}\).
- dual :: The LP whose solutions are the multipliers \(y\) giving an upper
  bound on the primal, minimized: \(\min\{b^\top y : A^\top y \ge c,\ y \ge
  0\}\). /Slide: Where the dual comes from./
- dual variable (multiplier) :: \(y_i\), the weight put on primal constraint \(i\) when
  combining constraints into a bound.
- dualization rules :: \(\le\) constraints get \(y_i \ge 0\), \(\ge\) constraints get
  \(y_i \le 0\), equality constraints get free \(y_i\); \(x_j \ge 0\) gives a
  \(\ge c_j\) dual constraint, \(x_j \le 0\) a \(\le\) one, free \(x_j\) an equality. Rebuild them from
  the bounding argument rather than memorizing. /Slide: The rules, once./
- involution :: The dual of the dual is the primal, exactly. Lab step 1 tests
  it.
- weak duality :: Every feasible \(x\) and \(y\) have \(c^\top x \le b^\top y\).
  One line of algebra. /Slide: Weak and strong duality./
- strong duality :: If the primal has an optimum, so does the dual, with equal
  value. Proved from Farkas' lemma, or from simplex termination.
- duality gap :: \(b^\top y - c^\top x\) for a feasible pair. Zero exactly when
  both are optimal.
- outcome table :: Primal and dual are both optimal with equal values, or one is
  unbounded and the other infeasible, or both are infeasible. No other pairing
  happens. /Slide: Four possible outcomes, not nine./
- infeasible or unbounded :: What presolve reports when it sees the dual is
  infeasible, which leaves both possibilities open for the primal.

* The dual as a certificate

- complementary slackness :: Feasible \(x, y\) are both optimal if and only if
  \(y_i (b_i - a_i x) = 0\) for every constraint and \(x_j ((A^\top y)_j - c_j) = 0\)
  for every variable. In words: a constraint with slack has price 0, and a used
  variable has zero reduced cost. /Slide: Complementary slackness./
- optimality certificate :: A primal–dual pair checked for feasibility of both
  and a zero gap, in exact arithmetic. Lab step 3.
- binding constraint :: One with no slack at the optimum, \(a_i x = b_i\). Only
  binding constraints can have a nonzero price.
- dual feasibility :: \(A^\top y \ge c,\ y \ge 0\). In the tableau: no negative
  entries in the objective row, the same test as unit 02's optimality criterion.
  /Slide: Reading the dual off the final tableau./
- reading duals off the tableau :: The optimal \(y\) is the slack columns of the
  final objective row, since a slack's reduced cost is \(-y_i\).

* The dual as prices

- shadow price :: \(y_i\), the rate the optimum changes per unit of \(b_i\):
  \(\partial z^* / \partial b_i = y_i\) at a nondegenerate optimum. What one more
  unit of a resource is worth. /Slide: Shadow prices./
- value function \(z^*(b)\) :: The optimum as a function of the right-hand side.
  Concave and piecewise linear, one piece per optimal basis.
- supergradient :: A vector \(y\) with \(z^*(b') \le z^*(b) + y^\top (b' - b)\)
  for all \(b'\): the concave counterpart of a gradient, and what \(y\) is where
  \(z^*\) has a kink.
- ranging (sensitivity analysis) :: The interval of \(\delta\) over which
  changing \(b_i\) to \(b_i + \delta\) keeps the current basis optimal, and so
  keeps the shadow price valid. Computed from slack column \(i\) of the final
  tableau with a ratio test. /Slide: Ranging: how long the price holds./
- cost ranging :: The same analysis for an objective coefficient \(c_j\): the
  basis stays optimal while the objective row stays nonnegative.
- sign convention :: A reported dual is \(\partial(\text{objective}) /
  \partial(\text{rhs})\) in the solver's own objective sense, so the same LP
  written as a min reports negated duals. /Slide: Sign conventions: an afternoon,
  as promised./

* The dual as an algorithm

- dual simplex method :: Simplex that keeps the objective row nonnegative (dual
  feasible) and pivots to remove negative right-hand sides (primal infeasibility).
  The primal simplex applied to the dual, on the same tableau. /Slide: The dual
  simplex method./
- dual ratio test :: With leaving row \(r\), enter the column minimizing
  \(T_{mj} / (-T_{rj})\) over \(T_{rj} < 0\). Keeps the objective row nonnegative.
- primal feasibility :: Every basic variable nonnegative, \(\bar b \ge 0\).
- infeasible row :: In the dual simplex, a leaving row with no negative entry reads
  "nonnegative combination = negative", so the LP is infeasible, and the row's
  multipliers are a Farkas vector.
- warm start :: Re-optimizing from the previous optimal basis after adding a cut
  or tightening a bound. The basis stays dual feasible, so the dual simplex needs
  only a few pivots. /Slide: Why branch-and-cut lives on it./
- cold start :: Solving from scratch.
- the seven hats :: Cutting planes, column generation, Lagrangian relaxation,
  Benders, the Hungarian algorithm, primal–dual approximation and KKT, each duality
  in a different setting. /Slide: This unit, wearing seven hats./
