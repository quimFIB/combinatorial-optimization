Régin's filter, step by step

Try: step from the value graph to the removed edges; then pick the run with a free value, where edges on a path to it survive. Static version: Régin's filter, on the example.

What it shows. The five stages of Régin's alldifferent filter: value graph, maximum matching, orientation, strongly connected components (and nodes that reach a free value), and the removal, with the Hall set behind every removed value.

  • The deck's example: no free value; one component {x1, x2, 1, 2}; four removals.
  • With a free value: value 5 is matched to nobody, so every edge on a path to it is kept, and x3 still loses 1 and 2 to the Hall set {x1, x2}.

Data. The reference value_graph, maximum_matching, _digraph, _sccs, AllDifferent.prune and hall_set, via slides/viz/traces/u18.py.

Compulsory parts and the profile

Try: pin C to start 2 (earliest = latest = 2) and the resource overloads; pin C to 4 and A to 2, and B loses start 2. Static version: A profile for three tasks.

What it shows. The deck's three tasks (durations 4, 3, 2, demand 1, capacity 2). For each task the dashed box is every time it might run, the solid box its compulsory part [latest start, earliest end). The bars below add up compulsory parts. Dots under a task are its start values: green kept, red removed by timetable filtering.

With the deck's windows, C's starts shrink to {0, 4, 5}, as on the slide.

Data. slides/viz/traces/u18.py runs the reference Cumulative.prune on all 378 window choices the sliders allow; the page only looks up the result.
