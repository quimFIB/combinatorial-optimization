The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Notation throughout: \(P = \{x : Ax \le b\} \subseteq \mathbb{R}^n\), with \(A\) an
\(m \times n\) matrix whose rows are \(a_1, \dots, a_m\). \(a_i x\) is the inner
product of row \(a_i\) with \(x\).

* Polyhedra

- halfspace :: \(\{x : ax \le \beta\}\) with \(a \ne 0\). /Slide: Halfspaces,
  polyhedra, polytopes./
- hyperplane :: The boundary \(\{x : ax = \beta\}\) of a halfspace.
- polyhedron :: An intersection of finitely many halfspaces, \(\{x : Ax \le b\}\).
  Always convex and closed.
- polytope :: A bounded polyhedron.
- standard form :: \(\{x : Ax = b,\ x \ge 0\}\). What simplex works in (unit 02).
  This unit uses \(Ax \le b\) instead; the conversions are on the same slide.
- slack variable :: The \(s \ge 0\) that turns \(ax \le \beta\) into \(ax + s = \beta\).
- valid inequality :: \(cx \le \delta\) is valid for \(P\) if every point of \(P\)
  satisfies it. /Slide: Faces./
- face :: \(P \cap \{x : cx = \delta\}\) for a valid inequality \(cx \le \delta\).
  Equivalently: turn some of the constraints of \(Ax \le b\) into equalities. \(\emptyset\)
  and \(P\) itself are the /improper/ faces.
- vertex, edge, facet :: Faces of dimension \(0\), \(1\), and \(\dim P - 1\).
- redundant inequality :: One that can be deleted without changing \(P\). A
  full-dimensional polyhedron has a unique minimal description: one inequality
  per facet, everything else redundant.

* Corners

- tight constraint :: Constraint \(i\) is tight at the point \(x\) when it holds
  with equality there, \(a_i x = b_i\): \(x\) lies on that constraint's line (its
  hyperplane), pressed against that wall. Tightness belongs to a constraint /at a
  point/: \(x + y \le 4\) is tight at \((2.5, 1.5)\) and not at \((1, 1)\). Other
  books say /active/ or /binding/, and matrix-minded ones say /tight row/, since
  constraint \(i\) is row \(i\) of \(Ax \le b\). /Slide: Tight constraints, and
  counting them./
- \(I(x)\) :: The set of constraints tight at \(x\), \(\{i : a_i x = b_i\}\).
- rank of the tight constraints :: The rank of the matrix whose rows are
  \(\{a_i : i \in I(x)\}\): how many independent directions the tight constraints
  pin down. Rank \(n\) means they fix \(x\) completely. Sometimes shortened to
  "tight rank"; not a separate term.
  /Slide: Tight constraints, and counting them./
- vertex :: A point \(x \in P\) that some objective \(c\) makes the /unique/
  maximizer of \(cy\) over \(P\). The geometric name for a corner. /Slide:
  Vertex, extreme point, basic feasible solution./
- extreme point :: A point of \(P\) that is not a strict convex combination
  \(\lambda y + (1-\lambda) z\) of two different points of \(P\). The convexity name.
- basic feasible solution (BFS) :: A point of \(P\) whose tight constraints have rank \(n\).
  The algebraic name, and the one a computer can check. In standard form it is
  usually stated with columns instead: the columns of \(A\) for the positive
  entries of \(x\) are independent.
- basic solution :: A point where \(n\) linearly independent constraints are tight,
  whether or not it lies in \(P\). Lab step 3 generates these and discards the
  infeasible ones. /Slide: Finding corners by trying pairs of constraints./
- basis :: A choice of \(n\) independent constraints whose equalities determine a basic
  solution.
- degenerate vertex :: A vertex with more than \(n\) tight constraints, \(|I(x)| > n\), so
  several bases name the same point. Example: adding \(3x - y \le 6\) to the
  running example makes \((2.5, 1.5)\) tight on 3 constraints with rank 2; in
  \(\mathbb{R}^3\), the apex of a square pyramid has 4 tight constraints and rank 3.
  Harmless geometrically; the reason simplex can cycle (unit 02), and the reason
  lab step 3 must deduplicate.
- pointed :: \(P\) has at least one vertex. For nonempty \(P\) this is the same as
  "contains no line" and as \(\operatorname{rank} A = n\). Anything inside
  \(x \ge 0\) is pointed. /Slide: Not every polyhedron has a corner./
- lineality space :: \(\{d : Ad = 0\}\), the directions along which \(P\) contains
  whole lines. \(P\) is pointed exactly when this is \(\{0\}\).
- crossover :: Walking from an arbitrary point of \(P\) to a BFS by moving along
  the null space of the tight constraints until the rank reaches \(n\). How solvers turn
  an interior-point answer into a basic one (unit 04).

* Two descriptions

- \(\operatorname{conv}(V)\) (convex hull) :: \(\{\sum \lambda_v v : \lambda \ge 0,\ \sum \lambda_v = 1\}\).
  /Slide: Two descriptions: Minkowski–Weyl./
- \(\operatorname{cone}(R)\) (conic hull) :: \(\{\sum \mu_r r : \mu \ge 0\}\). A
  /finitely generated cone/ when \(R\) is finite.
- recession cone :: \(\{d : Ad \le 0\}\), the directions in which \(P\) goes off to
  infinity.
- extreme ray :: A direction of the recession cone that is not a positive
  combination of two other, non-parallel, directions in it. The corners of a
  cone, in the same sense that vertices are the corners of a polytope.
- H-description :: \(P\) given by inequalities \(Ax \le b\).
- V-description :: \(P\) given as \(\operatorname{conv}(V) + \operatorname{cone}(R)\).
  Either description can be exponentially larger than the other: the \(n\)-cube
  has \(2n\) facets and \(2^n\) vertices.
- Minkowski–Weyl theorem :: Every polyhedron has both descriptions. In
  particular a polytope is the convex hull of its vertices.

* Fourier–Motzkin elimination

- projection :: \(\{x' : \exists x_k,\ (x', x_k) \in P\}\), the shadow of \(P\) with
  one coordinate dropped. Always a polyhedron. /Slide: Eliminating one variable./
- Fourier–Motzkin elimination (FM) :: Computing that projection by pairing every
  constraint that bounds \(x_k\) from above with every constraint that bounds it from below,
  using positive multipliers so \(x_k\) cancels. Gaussian elimination for
  inequalities.
- \(Z\), \(U\), \(L\) :: The constraints with \(a_{ik} = 0\), \(a_{ik} > 0\) (upper bounds on
  \(x_k\)) and \(a_{ik} < 0\) (lower bounds). FM outputs \(|Z| + |U|\cdot|L|\) constraints.
- nonnegative combination :: \(\sum y_i (a_i, b_i)\) with every \(y_i \ge 0\). The
  only way to combine inequalities that keeps them true; the one fact FM and
  Farkas both rest on.
- FM blow-up :: Constraint count going roughly \(m \to m^2/4\) per eliminated variable,
  almost all of it redundant. /Slide: Deciding feasibility, and the explosion./
- Chernikov's rule, Imbert's acceleration :: Bookkeeping that discards redundant
  FM constraints by tracking which original constraints each derived constraint came from. Not
  implemented in the lab; named in the slide notes.

* Farkas' lemma

- Farkas certificate :: \(y \in \mathbb{R}^m\) with \(y \ge 0\), \(y^\top A = 0\),
  \(y^\top b < 0\): a nonnegative combination of the constraints that reads \(0 \le\)
  (negative). It proves \(Ax \le b\) has no solution. /Slide: A certificate of
  infeasibility./
- Farkas' lemma :: Exactly one of: \(Ax \le b\) has a solution, or a Farkas
  certificate exists. Standard form: exactly one of \(\exists x \ge 0 : Ax = b\)
  and \(\exists y : A^\top y \ge 0,\ b^\top y < 0\). /Slide: Farkas' lemma./
- theorem of the alternative :: Any statement of the shape "exactly one of these
  two systems is solvable". Gordan's, Stiemke's and Motzkin's are relatives of
  Farkas'.
- tail trick :: Append the unit vector \(e_i\) to constraint \(i\) as extra columns that
  are never eliminated. After FM, a constraint \(0 \le c\) with \(c < 0\) carries its own
  certificate in those columns. Lab step 5. /Slide: Farkas, constructively./
- separating hyperplane :: A hyperplane with a set on one side and a point
  strictly on the other. Farkas, read geometrically: a point outside a finitely
  generated cone can be separated from it. /Slide: Farkas, geometrically./
- constraint qualification :: The extra hypothesis duality needs when the cone is
  not closed, as in SDP (unit 25). LP never needs one.
- NP ∩ coNP :: Linear feasibility has short "yes" certificates (a solution) and
  short "no" certificates (a Farkas vector, of polynomial bit size by Cramer's
  rule). /Slide notes: Farkas, constructively./

* Closing the loop

- fundamental theorem of LP (FTLP) :: If \(P\) is nonempty and pointed, then
  \(\max\{c^\top x : x \in P\}\) is either unbounded or attained at a vertex. So an
  LP is infeasible, unbounded, or solved at a corner. /Slide: The fundamental
  theorem of LP./
- LP relaxation :: The LP obtained from an integer program by dropping
  integrality. Why Part II needs this unit. /Title slide notes./
- Chvátal–Gomory cut :: A nonnegative combination of constraints with integer
  coefficients and the right side rounded down: Farkas plus rounding (unit 08).
  /Slide: Why this is the root of the trunk./

* In the lab

- row ~(a, b)~ :: One constraint, as a tuple of Python ints meaning \(a \cdot x \le b\). Exact
  integers throughout, so a certificate is a proof and not an approximation.
- ~normalize~ :: Divides a row by the gcd of its entries, so equal rows compare
  equal and FM can deduplicate.
- ~solve_exact~ :: Solves a square system in ~Fraction~'s, returning ~None~ when
  it is singular (the chosen rows are not independent, so not a basis). Given in
  ~colib.polyhedra~, used by step 3.
- basis enumeration :: Step 3's method: try all \(\binom{m}{n}\) row subsets as
  equalities, keep the feasible solutions.
